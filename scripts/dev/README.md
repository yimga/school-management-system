# Dev / ad-hoc scripts

Run from **project root** (e.g. `python scripts/dev/test_admin_access.py`).

- **test_admin_access.py** – URL accessibility and admin site check
- **test_backend_dashboard.py** – Backend dashboard template validation
- **test_backend_url.py** – /backend URL configuration
- **test_reverse_namespaces.py** – URL reverse by namespace
- **test_theme_visibility.py** – Theme (dark/light) visibility checks
- **test_url_functionality.py** – Dashboard URL and functionality
- **tmp_template_test.py** – Quick template filter test
- **validate_templates.py** – Template syntax check
- **validate_urls.py** – URL and template link validation
- **remove_people_auto_nullable_migration.py** – One-off: remove migration record from DB (run from project root)
- **reverse_admin_home.py** – One-off: print reverse('admin:home')
- **search_home_venv.py** / **search_reverse_home_venv.py** – Ad-hoc .venv search scripts

# RunMyCampus platform branding assets

Place the RunMyCampus logo assets here for **platform** (manager, base, verify, support) branding. Used when `PUBLIC_BRAND_MODE` is true.

| Filename | Use |
|----------|-----|
| `runmycampus-logo.png` | Full-color logo + "RUNMYCAMPUS" + tagline (light backgrounds): login hero, navbar, admin dashboard. |
| `runmycampus-logo-dark.png` | Dark-mode variant (inverted) for dark themes. Optional. |
| `runmycampus-icon.png` | Icon-only (Powerhouse shield): favicon, small headers, admin compact views. |

Source: RunMyCampus Brand Logo Asset Package (original, dark mode, icon-only, transparent as needed). Copy from your asset package or from the images provided in the branding plan.

# RunMyCampus Capacitor shell (SODP Wave E)

Android tablet shell wrapping the same PWA bundles as the browser portal.

- **Tokens:** `@capacitor-secure-storage-plugin` — never localStorage for capability blobs.
- **Debug LAN hub:** set `server.url` to `http://hub.local:8000` only in debug builds (`cleartext` permitted in dev flavor).
- **Lane 2:** Google Play listing, signing keys, and store screenshots are operator-owned deferrals.

```bash
cd companion-capacitor
npm install
npx cap add android
```

{% comment %} Service-worker reset / escape hatch. A deliberately MINIMAL, standalone page (no shell, no SW registration script) that unregisters every service worker for this origin and deletes every Cache Storage bucket, then redirects home. This is the one-click cure for a browser stuck on an old, cache-first service worker that keeps serving stale HTML/CSS/JS after a deploy — a state a normal hard-refresh cannot clear (refresh bypasses the SW for one request but never unregisters it). Served at /sw-reset/ with no-cache headers. Because the URL is new, even a stale cache-first SW has nothing cached for it and fetches this page fresh. The page intentionally does NOT include base.html / the registration script, so it cannot re-register the worker it just removed. {% endcomment %} Resetting the app…

{% trans "Complement" %}

{% trans "A color and its opposite on the color wheel, +180 degrees of hue. High contrast." %}

#2596be #be4d25

{% trans "Best for: High-impact designs, CTAs, logos" %}

{% trans "Split-complementary" %}

{% trans "A color and two adjacent to its complement, +/-30 degrees of hue from the value opposite the main color. Bold like a straight complement, but more versatile." %}

#2596be #6c25be #bea925

{% trans "Best for: Vibrant yet balanced layouts" %}

{% trans "Triadic" %}

{% trans "Three colors spaced evenly along the color wheel, each 120 degrees of hue apart. Best to allow one color to dominate and use the others as accents." %}

#2596be #be2596 #96be25

{% trans "Best for: Playful, energetic designs" %}

{% trans "Analogous" %}

{% trans "Three colors of the same luminance and saturation with hues that are adjacent on the color wheel, 30 degrees apart. Smooth transitions." %}

#2596be #25a5be #2587be

{% trans "Best for: Nature-inspired, calming interfaces" %}

{% trans "Monochromatic" %}

{% trans "Three colors of the same hue with luminance values +/-50%. Subtle and refined." %}

#2596be #041014 #145369

{% trans "Best for: Minimalist, sophisticated designs" %}

{% trans "Tetradic" %}

{% trans "Two sets of complementary colors, separated by 60 degrees of hue." %}

#2596be #9925be #be4d25 #49be25

{% trans "Best for: Rich, diverse color schemes" %}

{% trans "Square" %}

{% trans "Four colors at 90-degree spacing on the wheel. Balanced and bold." %}

#2596be #9925be #be4d25 #49be25

{% trans "Best for: Vibrant, balanced palettes" %}

{% trans "Achromatic" %}

{% trans "Neutrals only: black, white, and grays. No hue." %}

{% trans "Best for: Minimal, high-contrast, or typography-focused designs" %}

{% load i18n %} {% comment %} v3.54 (2026-05-21): Governance preview pane. Renders a proposed-change preview so an operator can see: - what's being changed, - the impact summary (from studio_control_impact route), - dependency warnings, - which audit-trail entry the change will produce, - rollback plan + confirm CTA.

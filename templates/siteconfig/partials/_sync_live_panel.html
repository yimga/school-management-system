{% load i18n %} {% comment %} Live sync evidence (2026-08-19). The Sync Center used to render one row of counters and then go stale until someone reloaded, so "is it syncing right now?" was unanswerable without a refresh reflex — and the counters alone cannot distinguish "12 rows moved" from "one row bounced 12 times", nor "nothing to do" from "nothing happened". This panel is PROGRESSIVE ENHANCEMENT: everything above it still renders and the "Sync now" form still works with JavaScript off. When JS is on, it polls siteconfig:sync_center_status and shows three independent kinds of evidence — the live link + cadence (is it connected, when does it act next), the run history (did cycles run and succeed), and the actual RECORDS that landed with their direction (the receipt). No inline event handlers: the CSP contract forbids on*= attributes, so the script is a nonced element that binds with addEventListener. Strings are passed through a JSON island so they stay translatable. {% endcomment %}

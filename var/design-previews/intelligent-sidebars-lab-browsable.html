The seven things that make a sidebar intelligent

Each card below is a live, working behaviour in the sidebar to the left — and each maps to a real, build-able feature on top of infrastructure the platform already has (the sidebar_registry, the command bar, the 7-layer config cascade, the badge-context keys). Toggle Operator/Tenant to see it work identically on both surfaces.

1 · Type-to-filter

Instant fuzzy filter inside the sidebar — the #1 gap today (the operator sidebar has 70+ items and no search). Empty groups fold away automatically.

Try: press / and type “aud”, “sign”, “grade”…

2 · Adaptive “For you”

A smart top section that learns your most-used destinations and floats them up — beyond manual pinning. Hot items get a subtle ★ often tag.

Try: toggle Adaptive in the toolbar.

3 · Live awareness badges

Counts that mean something — pending approvals, open incidents, unread messages — wired from the registry’s existing badge_context_key, polled lightly (no websocket needed).

Try: click Simulate live update.

4 · Pin to Quick access

One click promotes any item to a personal Quick-access band (already persisted today via DashboardUserPreference).

Try: hover an item and click the ☆.

5 · Keyboard-native

/ focuses filter, ↑/↓ walk results, ↵ navigates, ⌘K bridges to the existing command palette.

Try: / then arrow keys.

6 · Density & shape

Compact / Comfortable / Spacious — a real per-user + per-tenant config field, so the same nav fits a power operator and a first-time parent.

Try: the Density switch above.

7 · One brain, two skins

Operator (dark) and every tenant role (light, indigo/emerald) render from one sidebar_registry SOT — so intelligence ships everywhere at once, never forked per shell.

Try: the Operator/Tenant switch above.

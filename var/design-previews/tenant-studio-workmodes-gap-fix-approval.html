Updated Diagnosis

Must be designed out
  • The shell is stacked, not composed. Header, command bar, mode bar, hero, cockpit canvas, Studio canvas, mode workspace, sticky preview bar, and right rail are all acting like separate page owners.

  • All modes inherit the same broken geometry. Automation, Outputs, Launch, Control, Feature Controls, Workflow Center, Report Builder, and preview-heavy setup pages need mode-specific canvases under one shared contract.

Option C - Canvas-first live builder

Stop making preview fit the form. Make the form serve the preview.

This option removes inline preview as the main work area. The live preview becomes the central canvas, settings move into an inspector, and the left outline lets users jump between editable regions. This is closer to how serious builders work: canvas, inspector, breakpoints, role/state switchers, and review/compare.

Rule 1

Preview is never squeezed

Inline previews become thumbnails only. Full preview uses canvas, drawer, popout, or new tab.

Rule 2

Inspector edits selection

Users select a page region and see only relevant settings, reducing massive forms.

Rule 3

Full width by default

Studio, Django admin, report builders, dashboards, forms, communications, and launch pages use the available canvas.

Rule 4

Proof before publish

Role, device, draft/live, tenant/operator, accessibility, and no-overlap checks must pass before commit.

Space intelligence audit — Django /admin/ (operator + tenant)

Honest read of what is still wrong after v13 density patches. The problem is not “one more !important.” It is stacked chrome, duplicate actions, low-value metrics, and cascade debt across every admin surface. This page is the findings board + before/after for the next careful wave (v14). Open in a browser; approve the sequence before any code.

Why prior ships still felt cramped: v13 fixed some Unfold max-w-* and tall M2M lists, but the page still burns fold 1 on three headings + three metric chips + duplicate Add/Filters. Width fill without chrome collapse = still feels wasted and cramped.

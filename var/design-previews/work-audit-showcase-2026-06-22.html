3 · Tools dock popupgenuine bug + proposed fix

The Tools tray uses overflow:hidden + a position:relative shell, so a popup opened from inside it gets clipped/trapped behind the tray. The fix portals the popup out, displaced to a clear area, in front (above the tray's z-index) — without removing the overflow clip the horizontal-overflow CI gate depends on.

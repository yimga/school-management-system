Route ownership drift

Shared template object-coercion defect

Readiness false negative

The 25-point runtime check reads legacy slug fields even though provisioning creates real dashboard pack and tenant layout assignments.

Repeated sidebar groups

Django regroup only combines adjacent records. A tenant-defined interleaved item order repeats entire section headings.

Catalog has no content hierarchy

Trust, compatibility, rollback and install instructions are all expanded inside every card. Missing remote preview URLs have no resilient fallback.

Host routing is functioning

Signed-out Configuration, Settings, Catalog, Finance and canonical Offline routes redirect to Gilead’s tenant login. The failures are route-level, not “Campus Not Found.”

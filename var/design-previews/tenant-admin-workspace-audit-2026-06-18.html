Why you still see gold + empty/duplicate cards

A browser tab or installed PWA opened before the latest deploy keeps serving the old cached CSS/JS until the new service worker takes control. The SW is set to auto-update (updateViaCache:'none' + registration.update() on every load + guarded controllerchange reload), but an already-open session can lag.

Definitive fix & verification (please run on new-school.runmycampus.com)

  1. Open DevTools → Application → Service Workers → click Unregister.
  2. Application → Storage → Clear site data.
  3. Hard reload (Ctrl+Shift+R). Close any other tabs/PWA windows of the site first.
  4. Confirm the version: DevTools → Console → run caches.keys() — you should see sms-v4.04.23-…. If you still see an older version, the deploy hasn't reached the tenant subdomain yet.
  5. Confirm the theme: Console → getComputedStyle(document.body).getPropertyValue('--personality-accent') — should be #4f46e5/indigo, not gold.

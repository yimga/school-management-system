Modals & Confirm Lab — Surface 7

The platform already has a premium native-<dialog> sheet system (rmc-sheet + window.RMCSheet: focus-trap, ESC, backdrop, responsive bottom-sheet). But destructive actions across ~35 JS files still call the raw browser confirm() — unstyleable, un-branded, inaccessible, blocking. The modal engine adds a declarative [data-rmc-confirm] + a promise-returning window.RMCConfirm() that renders on the existing sheet — so one line replaces every native confirm().

Try it — declarative + programmatic

Declarative: <button data-rmc-confirm="Delete this invoice?" data-rmc-confirm-tone="danger" data-rmc-confirm-ok="Delete"> — the engine intercepts the click, confirms, then re-runs the original action (submit / navigate / onclick). Programmatic: if (await RMCConfirm({title, message, tone:"danger"})) { … } replaces window.confirm() in a single line. RMCAlert() replaces window.alert().

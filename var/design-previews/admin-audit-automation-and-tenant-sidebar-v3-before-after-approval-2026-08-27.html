Current permissive path

False confidence is possible

token scan->render proxy->PASS

This path can pass without interacting with the tenant sidebar in a browser. It also lacks source-bound freshness.

Required strict path

Every claim has provenance

SHA->real hosts->behavior->sealed artifact

A proxy remains useful source evidence, but it cannot impersonate browser proof or overwrite its artifact.

  • 3Offline operations rebase over the latest server revision instead of replacing it.

Proof foundation

  • 1Separate render-contract and real-browser evidence.
  • 2Complete workflow triggers and mandatory tenant/operator browser coverage.
  • 3Source/server, browser, then adversarial audit loops.
  • 4Fail-closed freshness and artifact integrity verification.

Non-negotiable preservation

  • 1Native Django tables and real form actions remain functional.
  • 2Page awareness comes from route semantics and permissions, not duplicated page furniture.
  • 3No operator-only controls on tenant pages and no tenant data in operator preference scope.
  • 4Build, cache-bust and service-worker IDs move together.

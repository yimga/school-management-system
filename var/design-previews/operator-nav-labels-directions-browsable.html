Each sits in a realistic topbar (brand left, controls right) so you can see how it handles the tight middle slot. Resize your window to feel how each behaves.

My read: B (Smart overflow) is the most robust — it literally cannot ever show a bare icon and reuses the dropdown you just approved. A (Compact chips) is best if you want all 8 visible at once and accept denser text. C (Glide rail) is the most distinctive and scales to any number of items. A + B together is the belt-and-suspenders combo (compact labels, overflow only when truly out of room).

All four are pure CSS (B reuses the no-JS native <details>); none change the 54px header height. Pick one (or a combo) and I’ll implement it on cp-primary-nav--rail only, so the non-rail include sites are untouched. Pixel-approximate mock — real tokens/brand apply on implementation.

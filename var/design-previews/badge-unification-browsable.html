The proposal — one quiet-luxury grammar (extends the existing .rmc-badge)

Six semantic tones, one spelling, light + dark correct by token

Tinted (not loud-solid) backgrounds at 7–14% color-mix, pill radius, tabular weight — the existing .rmc-badge grammar, with one new --brand tone added to cover today's bg-primary.

After approval: exact build scope

One shared tenant workspace system, then page-by-page closure.

The next level is not another cosmetic pass. It is a shared layout contract used by Studio, Workflow Center, Feature Control, report card builder, and every tenant configuration page that currently renders as a tall nested shell with wasted space.

Tenant-wide

Build once

  • LayoutCreate a reusable command-workspace shell: compact header, mode strip, left task rail, main live workbench, right impact sidecar.
  • ChromeRemove duplicated host mode/work mode panels, duplicated search blocks, and assistant blocks that push work below the fold.
  • PreviewStandardize live preview states: loading, blocked iframe, HTML fallback, PDF fallback, role preview, and publish gate.
  • SafetyEvery publish-capable page shows impacted roles, menus, workflows, audit record, and rollback availability before save.

Audit sweep

  • StudioOverview, Experience, Automation, Outputs, Launch, and Control work modes.
  • WorkflowWorkflow Center, approval hub, import hub, migration wizard, visual workflow designer, and Studio embeds.
  • ControlsFeature controls, capability toggles, policy impact pages, RBAC/admin decision pages, and rollout/rollback surfaces.
  • PreviewsReport card builder, dashboard-by-role, theme/customizer, forms/admissions, communications, launch preview-by-role.

Done means

  • No blanksNo giant empty panels, failed preview frames, hidden controls, or duplicate bottom/help widgets left behind.
  • No missesRoutes and templates are inventoried, grouped, fixed, then rechecked against the inventory.
  • ProofBrowser screenshots for key pages, Django checks, compileall, template scan, and a gap-analysis report.
  • CommitOnly after validation passes, commit and push the approved implementation to main.
1. InventoryFind every page using Studio-like nested workspace, iframe preview, feature-control, workflow, or report-builder patterns.
2. RefactorMove those pages onto the shared workspace contract without changing business logic or tenant contracts.
3. ValidateOpen the pages in browser, inspect role/mode variants, run automated checks, and record remaining gaps.
4. CloseFix the gaps found by the audit, rerun validation, then commit and push when the sweep is clean.
Apply onceUse one shared Studio workspace component so all current and future tenants inherit the rework.
Do not fake previewsIf iframe/PDF fails, show a compact preview health state and actionable fallback, not a blank page.
Preview modes firstExperience, Report cards, Outputs, and Control get priority because they have the biggest wasted space.
Keep sidebars usefulGlobal tenant nav remains outside Studio. Studio only owns local mode and task navigation.
Audit before implementationAfter approval, implement behind shared CSS/templates, then crawl every mode and preview surface.

Density 3A — bento rows hug content

The desktop dashboard contract forced every bento row to a 236 / 200 / 210px floor, so a content-light card (e.g. a short list or a 3-row table) still stretched to the floor and manufactured grey emptiness — ~250–400px wasted per view. The rows are minmax(floor, auto), so lowering the floor only removes the manufactured emptiness — it can never clip content (tall charts still grow past it). The designed 3-column bento placement is unchanged.

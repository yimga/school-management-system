APPROVAL v15.1 · Top-tier Admin OS · innovation inside the OS

One product system. Six job-true surfaces. Twelve innovations that never break the OS.

Top-of-line UI is not “everything looks identical” and not “everything looks random.” It is one Admin OS (tokens, type, motion, action grammar, host voice) expressing ruthlessly different layouts per job (discover / scan / edit / audit / decide / dossier). Operator and tenant share the OS; they do not share the wrong CTAs.

Consistency (the OS)

Same type scale, hairlines, radii, Save ▾ grammar, ⌘K, empty/skeleton states, focus rings, density steps, and host voice rules. A user who learns one control pattern can use every page without relearning chrome.

Intelligence (the job)

Layout, tools, rail facts, and fold-1 content change with the job. Blur test: index ≠ list ≠ form ≠ history ≠ delete. If chrome is inert on this page, it is deleted — never greyed for “consistency.”

10 · Innovation inside the OS creative — but every idea reuses the same primitives

Rule: invent behaviors, not new visual languages. Each card below names the shared OS lock (what stays identical) and the page-smart payload (what changes). That is how Linear / Apple Settings / Stripe stay consistent while feeling sharp.

I1 · Selection gravity

Band morphs into bulk dock

3 selected · Activate · Deactivate · Delete ▾ · Esc
Table rows stay put — chrome adapts

Selecting rows replaces the list band’s Add/Filters with bulk actions. Deselect restores. No second toolbar.

OS lock: same band height, radii, primary/danger grammar · Smart: Scan archetype only
I2 · Row peek sheet

Inspect without leaving the list

Users table…

Space / click chevron opens a right sheet with record summary. Enter opens full Edit. Same sheet component as Filters.

OS lock: one sheet primitive · Smart: fields shown = list_display + key status
I3 · Dirty Save pulse

Save ▾ shows what changed

Save · 3 fields▾

Unchanged = green “Save”. Dirty = amber “Save · N fields” + menu lists changed labels. Same split control — smarter state.

OS lock: Save ▾ component forever · Smart: Edit archetype + dirty field map
I4 · Section radar

Edge dots for long forms

Identity · Access · Permissions…

Vertical radar on the far edge jumps sections. Active dot = viewport. Same hit target language as tools column.

OS lock: tool-column sizing · Smart: dots = real fieldsets on this form
I5 · Focus mode

Fullscreen editor on demand

Focus · rail & tools hidden⌘.

⌘. collapses rail + tools; MAIN goes full bleed. Escape restores OS geometry. Ideal for SiteSettings monsters.

OS lock: never invent a second form skin · Smart: Edit only; state in session
I6 · Disclosure primitive

One numbered <details> system

1 · Permissions ▸ 12
2 · Groups ▸ 2
3 · Advanced ▸ collapsed

Same component for M2M, fieldsets 3+, catalog “View all”, related-on-delete. Count badge always visible when collapsed.

OS lock: one disclosure grammar · Smart: default open/closed by archetype + model policy
I7 · Pin & recent

Discover remembers intent

★ Users ★ Schools Site settings
Recent: Invoices · Teachers · Themes

Pins + recent row above catalog. Operator defaults ≠ tenant defaults. Same pin chip component.

OS lock: chip + search grammar · Smart: host-default pins; per-user override
I8 · Page keymap

? opens this page’s shortcuts

/ search · A add · F filters · ⌘K jump
List keymap ≠ Form keymap — same drawer chrome

Tools “?” always opens the cheatsheet drawer. Contents are archetype-specific. Learn once, apply everywhere.

OS lock: drawer + kbd styling · Smart: shortcut set from kill matrix
I9 · Live rail only

Facts that change actions

Selected 3bulk ready
Dirty 2email · role

Rail never shows Scope manifesto. Only live counters, active filters, dirty fields, related risks on Decide.

OS lock: rail card chrome · Smart: payload from page state machine
I10 · Host accent whisper

Identity without forking the OS

Op primary = green/sky
Ten primary = school teal

Tenant primary CTA + focus ring use school brand. Operator stays fleet. Layouts identical — accent placement locked.

OS lock: where accent may appear · Smart: which color token (fleet vs school)
I11 · Model policy pack

Smart defaults per model class

User → collapse Permissions
SiteSettings → tabs + focus mode default-on
School → identity 2-up open

Creativity at the model layer, not one-off CSS. A small policy map drives disclosure + focus defaults. New models inherit.

OS lock: disclosure + focus primitives · Smart: policy table, not bespoke templates
I12 · 3-click SLA

Product metric, not decoration

Index / → List → Edit
≤ 3 interactions · both hosts

Hard product rule: from Discover search to Edit ≤3 interactions. Forces search quality + kills CTA walls. Measured in Playwright.

OS lock: journey grammar · Smart: gate fails if a path needs 4+

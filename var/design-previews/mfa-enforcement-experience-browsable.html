RunMyCampus · Security

Two-factor enforcement — strict · grace · optional

Privileged roles still require 2FA (the Salesforce / AWS / GitHub posture). What's now configurable per tenant is how that requirement is rolled out — so a school admin is never hard-walled out of their own dashboard on the first click.

1 · The bug this fixes

Your ADMIN account is a required-MFA role with no enrolled device, so the old middleware redirected every navigation straight to the setup wizard. The dashboards you built were live — you just couldn't reach them.

click sidebar → /portal/…→ 302 /mfa/setup?next=…→ 302 /wizards/mfa_setup/ (the "ugly page")

Now the same account, with the tenant set to optional or grace:

click sidebar → /portal/…→ 200 your real dashboard renders+ a persistent “set up 2FA” nudge

2 · The three modes (tenant-configurable, default unchanged)

strict

Hard wall

Require 2FA before any access. This is the platform default — every existing tenant behaves exactly as before. Zero behavior change unless someone opts in.

grace recommended

Grace window

Full access immediately + a nudge; hard-enforced only after N days (measured from each user's join date). The Salesforce/Shopify rollout pattern — no first-click wall for new owners.

optional

Nudge only

Never blocks; shows the prompt only. Ideal for this test / demo tenant so you can walk the whole product without juggling an authenticator.

Users who already have 2FA are never affected by this setting — it only governs how required-role users without a device are treated.

3 · The persistent nudge (grace + optional) — shipped, rendered live

6 · Why mandatory 2FA is correct — what the giants do

PlatformAdmin / privileged 2FA
SalesforceMandatory for all logins since Feb 2022 — contractual, no opt-out
AWSMandatory for root users of management accounts (2024)
Microsoft 365 / AzureEnforced for all admin portal sign-ins (2024)
GitHubMandatory 2FA for everyone who contributes code (2023)
Shopify / Stripe / GoogleRequired for staff & admin dashboards

We keep the mandate (default strict) and add the graceful rollout they all use. We don't weaken security — we fix the experience.

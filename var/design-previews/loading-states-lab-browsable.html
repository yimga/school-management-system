Loading-States Lab — Surface 5

The top progress bar, skeleton grammar, and form submit-pending already exist. The loading engine connects them to the operations that today give zero feedback — slow action buttons, downloads, and async sections. Click the buttons below.

Slow action button — Before

Today: click "Export CSV" and… nothing visible happens for a few seconds until the file downloads. Users click again (and again), firing duplicate exports.

Slow action button — After

The engine locks the button, swaps the label to "Exporting…", shows a spinner + the top progress bar, and blocks double-clicks — for ANY [data-rmc-loading] button and every a[download] link, no per-page JS. Watchdog releases it so it's never stuck.

Async section — skeleton on load

While an async section fetches, the engine fills it with a content-shaped skeleton (from the existing grammar) instead of a blank gap — then the real rows replace it. Wired to HTMX targets via [data-rmc-skeleton="list"].

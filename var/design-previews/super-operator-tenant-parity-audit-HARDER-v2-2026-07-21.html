The consistency law (both hosts, non-negotiable)

If it isn’t equal on operator and tenant, it isn’t done
One product, two scopes. Operator sees the fleet. Tenant sees one school. Layout, archetypes, tag language, masthead, spacing, and color semantics must match — only the nouns and numbers change.

1 title system

Masthead only: title + live chips + 1–2 actions + optional ⓘ. Never explain strip + center frame + studio header stacked.

Live tags or none

Ban static Operational / hardcoded ready. Chips must change with state. Wallpaper tags are worse than no tags.

Air by subtraction

Cramping is caused by band count, not lack of padding. ≤2 chrome bands above work, then roomier section gaps.

02

Purpose color — interesting, not rainbow chaos

Color encodes job + host. Text stays high-contrast on every surface

Mission · coral

Landings / command. Personality allowed. Pulse, pillars, one primary CTA. Host tint in chrome only.

Fleet · blue

Lists / search. Sticky filters. Full-bleed table. Chips for counts. No Option-A novel.

Money · green

KPIs always visible. Past-due / PSP chips. Ledger first. Never collapse money.

Setup · violet

Blockers first. Progress chip. Definitions in ⓘ. One CTA per unmet item.

Monitor · sky

Stateful health pills. Time context. Drill-in. “All clear / Degraded / Breach” only.

Innovation backlog (creative, shippable)

Both hosts

Semantic color spine

3px archetype accent on masthead + KPI cards. Host frame tint (indigo / teal) on shell edge only — never on body text. Instant orientation without rainbow UI.

Both hosts

Shared masthead partial

rmc_page_masthead with slots: title, chips[], primary, secondary, info_tag. One implementation — operator and tenant import the same component.

Tenant

Admin Home convergence

Collapse five hubs into one Mission page with rails into Setup / Money / Fleet. Sidebar shows one “Admin” root — consistency with operator Home.

Both hosts

Tag vocabulary lock

Exactly four live states with fixed colors: healthy · attention · needs setup · breach. i18n keys shared. No synonyms, no Operational.

Both hosts

Adaptive density

Lists denser; Setup maps airier; Mission expressive. Driven by data-page-archetype — not hand-tuned per template. Solves cramping without bloating padding everywhere.

Both hosts

Visibility gate

New verifier: no text parent with overflow:hidden + sticky; chip contrast check; band-count ≤2 above [data-rmc-work-root]. CI fails on wallpaper badges.

08

Visibility & anti-cramp contract (prove in every mock)

This audit’s after-mocks already obey: wrapping chips (no ellipsis by default), minmax(0,1fr) grids (no horizontal bleed), solid panels under text (no type on busy media), high-contrast badges, no sticky overlay covering content, dual-host columns stack on narrow screens instead of crushing.

No blocking

Sticky filters reserve height in flow. Modals/drawers only on demand. Copilot rail never covers primary numbers.

No cramping

≤2 chrome bands. Section gap 1.25–1.5rem after subtraction. Dense only inside tables.

No bleeding

Host color on frame chrome only. Archetype color on accents/eyebrows. Body text always paper-ink on paper.

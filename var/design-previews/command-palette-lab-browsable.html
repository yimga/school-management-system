Command Palette Lab — Audit → Elevate

The sibling of the intelligent sidebar. Today the platform ships two palettes both bound to ⌘K with no frequency, no highlighting, no federation, and zero operator config. This is the proposed one-engine elevation — interactive, so you can feel it before we build it.

What we found (the "before")

  • Two palettes, one key. rmc-command-palette.js & rmc-command-bar.js both grab ⌘K — load order decides the winner.conflict
  • 173 actions, hardcoded. No cascade config — operators can't toggle or scope it per-tenant.not configurable
  • Recent only, no frequency. A 6-item localStorage list; no usage-weighted ranking.shallow
  • No matched-text highlight. You can't see why a result ranked.opaque
  • Sidebar registry not federated. Misses ~30–40% of nav targets.gap

The elevation (the "after")

  • One engine behind ⌘K — unifies both palettes, keeps the rich one's powers (page-aware, AI, voice).unified
  • Frequent + Recent adaptive bands (same usage model as the sidebar).adaptive
  • Fuzzy match + live highlight of the matched substring.legible
  • Federated sources — Nav · Actions · Sidebar · AI — with source chips & live badges.complete
  • Configurable via cascade (platform→school→user) + per-user pinning.genius

What competitors do better (and these options fix)

  • Canvas / ClassLink: role is obvious before credentials — Option B.
  • PowerSchool / Blackbaud: parent invite is a first-class path, not footer text — Options A & D.
  • Google Workspace: one focal card, SSO above password — Options C & B.
  • Linear / Notion: no app chrome on auth — remove breadcrumbs & stacked cards — Option C.
  • Your current screen: generic orange slab + validation noise — all options use tenant brand tokens, inline validation, and calm hierarchy.

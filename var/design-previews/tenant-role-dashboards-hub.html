Quick verification on live tenant

  1. Pull latest main and restart the app.
  2. DevTools → Application → Service Workers → Unregister → Storage → Clear site data → hard reload.
  3. Log in as admin → backend dashboard → expect onboarding hero if school still onboarding.
  4. Log in as teacher / parent (test accounts in AGENTS.md) → expect role-specific hero, no full-page black void.
  5. Open completed MFA wizard → review banner visible, page height matches content.

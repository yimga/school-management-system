# Rollback runbook: Phase 5 (program closure)

## Trigger conditions

- `verify_global_governance_plan_completion.py --strict` exits non-zero after a marked-DONE phase.
- `generate_system_closure_map.py --write` reports a regression in any phase exit gate.
- Sovereignty trust score (Phase 6 turbo) regresses for a Tier-1 anchor country and the closure claim is impacted.

## Safe revert

1. Demote the program from `CLOSED` to `IN_PROGRESS` in the register.
2. Identify the failing exit gate (`P0D` / `P1` / `P2C` / `P3E` / `P4G`) and run that phase's specific rollback runbook.
3. Update SOT §11.4 master row from "closure" to "closure paused" with proof of the failing verifier.
4. Re-run the aggressive audit loop until it returns to clean.

## Forbidden

- Reopening closure without surfacing the regression to the operator.
- Hand-editing the register to mark items DONE without rerunning the proof verifier.

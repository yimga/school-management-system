# Rollback runbook: Phase 1 exit

## Trigger conditions

- Language overlay regression test fails on `_seed_country_localization.py`.
- `get_languages("CM")` (or any of the 11 affected ISO codes) returns empty.
- Doc reconciliation introduced a fact that the codebase contradicts.

## Safe revert

1. `git revert` the offending fix commit; the regression bug returning is acceptable in the short term.
2. Re-run the language regression test to confirm the revert restored the prior known state.
3. Reset register status `P1-language-overlay-fix` -> `IN_PROGRESS`.
4. Open a SOT §11.4 amendment row.

## Forbidden

- Disabling the regression test instead of fixing the merge.
- Marking the bug `EXTERNAL_BLOCKED`; the fix is in-repo and small.

# Communication Workflows
## Complete Guide to Messaging, Groups, and Announcements

**Target Audience:** All Users (Teachers, Parents, Administrators)  
**Difficulty:** Beginner  
**Estimated Time:** 5 minutes per message

---

## Overview

This guide covers all communication features: messaging, group chats, announcements, and parent contact requests.

---

## Messaging System

### Individual Messages

**How to Send:**
1. Navigate to Messages (`/accounts/messages/` or sidebar)
2. Click "New Message"
3. Select recipient
4. Type message
5. Attach files (optional)
6. Click "Send"

**Who Can Message:**
- Teachers → Parents, Students, Other Teachers
- Parents → Teachers, School Staff
- Administrators → Anyone

---

### Message Threads

**What They Are:**
- Conversations between users
- Organized by subject/topic
- Persistent history

**How They Work:**
1. First message creates thread
2. Replies added to thread
3. Thread shows full conversation
4. Mark as read/unread

---

## Message Groups

### Department Groups

**What They Are:**
- Auto-created groups for departments
- All teachers in department are members
- Used for department-wide communication

**How to Use:**
1. Navigate to "Message Groups"
2. Find your department group
3. Click to open
4. Send message to all members

**Who Can Create:**
- Administrators
- Department Heads
- Teachers (for their department)

---

### Custom Groups

**How to Create:**
1. Navigate to "Message Groups"
2. Click "Create Group"
3. **Fill in:**
   - Group Name
   - Description
   - Members (select users)
4. Click "Create"

**Use Cases:**
- Subject committees
- Event planning
- Special projects
- Class parent groups

---

## Announcements

### Creating Announcements

**Who Can Create:**
- Administrators
- Leadership
- IT Admin

**Steps:**
1. Navigate to "Announcements" or `/communication/announcement/create/`
2. **Fill in:**
   - Title
   - Message
   - Banner Type (Info, Success, Warning, Danger)
   - Start Date (optional)
   - End Date (optional)
3. Click "Publish"

**Where They Appear:**
- All dashboard pages
- Parent portal
- Teacher portal
- Student portal

---

### Announcement Types

**Info (Blue):**
- General information
- Updates
- Reminders

**Success (Green):**
- Achievements
- Positive news
- Confirmations

**Warning (Yellow):**
- Important notices
- Deadlines
- Warnings

**Danger (Red):**
- Urgent alerts
- Critical information
- Emergencies

---

## Parent Contact Requests

### For Parents

**How to Submit:**
1. Navigate to "Contact School" (`/portal/parent/contact-school/`)
2. **Fill in:**
   - Subject
   - Message
   - Select recipient (Teacher, Admin, etc.)
   - Attach files (optional)
3. Click "Submit"

**What Happens:**
- Request sent to Secretary/Executive Assistant
- Triage and assignment
- Response sent to parent

---

### For Staff (Triage)

**Who Handles:**
- Secretary
- Executive Assistant
- Virtual Assistant

**Steps:**
1. Navigate to "Contact Requests" (`/portal/staff/contact-requests/`)
2. Review requests
3. **Actions:**
   - Assign to appropriate staff
   - Respond directly
   - Mark as resolved
4. Track status

---

## File Attachments

### Supported Files

- **Documents:** PDF, Word, Excel
- **Images:** JPG, PNG, GIF
- **Size Limit:** 10MB per file

### How to Attach

1. Click "Attach File" in message
2. Select file
3. Upload
4. File attached to message

## Best Practices

### For Teachers:
- Respond to parent messages within 24 hours
- Use groups for class-wide announcements
- Keep messages professional

### For Parents:
- Use contact form for formal requests
- Use messages for quick questions
- Check messages regularly

### For Administrators:
- Use announcements for school-wide information
- Create groups for committees
- Monitor contact requests

---

## Common Issues

### Issue: Can't send message
**Solution:** Check recipient exists and you have permission to message them.

### Issue: Message not received
**Solution:** Check recipient's notification settings and message filters.

### Issue: Group not visible
**Solution:** Verify you're a member of the group or department.

# Outreach playbook (founder/operator)

**No automation tools required** beyond email and calendar. All copy is a starting point—localize and shorten.

## LinkedIn (connect + one follow-up)

**Connect note (max ~300 chars):**  
*Hi {first}, I build RunMyCampus—operations and control-plane software for {region} K–12. If you ever want a 20-min look at how we handle domains, academic structure, and reporting in one place, I’m happy to share. – {name}*

**Follow-up (day 3):**  
*Thanks for the connect. I’m not pitching today—if a 20-min call would help you compare how you run term setup and comms today vs a tenant-isolated stack, I’ll send a Calendly link. If not, no problem.*

## Email (cold, short)

**Subject:** 20 minutes — school ops stack (not curriculum)

**Body:**  
*{first},*  
*We help private/independent schools run operations on one tenant—domains, year/term structure, and reporting with evidence for leadership. I’m a founder, not a call center; I only reach out to {segment} I can actually support.*  
*If you have 20 minutes in the next two weeks, I’ll walk the real product (no PowerPoint only).*  
*— {name}*  
*P.S. If this isn’t you, who owns IT + academics setup? Happy to have you forward.*

## WhatsApp (if culturally normal)

*Hi {first}—{name} from RunMyCampus. Sent you a short email about a 20-min product walkthrough for school ops. OK to send a 2-line summary here?*

## Referral request (after a good pilot touchpoint)

*If this was useful, I’d appreciate **one** intro to another {role} in your network. No pressure—only if you genuinely think they’d value the same visibility.*

## Follow-up sequence (7–10 days)

1. **Day 0:** First message.  
2. **Day 3:** “Still interested in 20 min?” + one line of proof (e.g. “evidence + scheduled reports, not a fake deck”).  
3. **Day 7:** “Closing the loop on my side—if timing’s bad, tell me a better quarter.”

## Demo booking

- **Rule:** 45 minutes max; **1 screen share**; you drive from `DEMO_SCRIPT.md`.  
- **Book:** You own the link (Calendly/Booking built-in, etc.).

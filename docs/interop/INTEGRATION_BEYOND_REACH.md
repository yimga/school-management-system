# Beyond reach — interop wedges 44–45 (next horizon)

Improvements that push RunMyCampus **past** standard district/LMS parity. Track in product backlog; not all are shippable without partnership or major effort.

## Wedge 44 (roster / LMS glue)

| Horizon | Why “beyond reach” |
|---------|-------------------|
| **Real-time roster graph** | Bi-directional sync with conflict resolution UI; sub-second propagation. |
| **AI-assisted roster reconciliation** | NLP diff summaries for district data stewards. |
| **Universal SIS adapter SDK** | Third parties ship connectors; we certify — ecosystem flywheel. |
| **Zero-trust interop mesh** | mTLS everywhere, workload identity for district ETL jobs. |
| **Global CDN edge for OneRoster** | Read replicas per region; GDPR data locality for API responses. |

## Wedge 45 (identity)

| Horizon | Why “beyond reach” |
|---------|-------------------|
| **Continuous authentication** | Step-up based on risk score + device posture (beyond MFA). |
| **Cross-tenant federation** | Trust fabrics for chains of academies / ministries without duplicate users. |
| **Verifiable credentials (W3C VC)** | Diplomas and staff badges as presentable credentials. |
| **Passwordless default for students** | Passkeys + guardian approval for minors. |

## Meta

| Theme | Direction |
|-------|-----------|
| **Observability** | OpenTelemetry spans per IdP and per OneRoster collection; SLO dashboards in product. |
| **Partner co-sell** | Automated “integration health score” for marketplace listings. |

# Workflow Center – Future Improvements

**Date:** January 28, 2026  
**Scope:** Admin Workflow Center, Teacher Workflow Center, Parent Workflow Center.

---

## Admin Workflow Center

| Improvement | Description | Priority |
|-------------|-------------|----------|
| **Recommended next step** | Hero or top card: "Focus this week: Add students" (or "Run rollover", "Publish term results") based on progress (0 students → add students; year end → rollover). | Medium |
| **Step completion indicators** | Optional checkmark or "✓" when a step is "done" (e.g. Year setup ✓ when classrooms > 0, Onboarding ✓ when students > 0). | Low |
| **Quick stats → step** | Clicking a hero badge (e.g. "Classrooms: 5") could scroll or highlight the relevant step. | Low |
| **Export workflow state** | Optional PDF/CSV summary of workflow state (steps, counts) for reporting or handover. | Low |

---

## Teacher Workflow Center

| Improvement | Description | Priority |
|-------------|-------------|----------|
| **Today's tasks** | Short list: "Take attendance Form 5A", "Enter marks English Seq 2" (from assignments + missing evaluations or timetable). | Medium |
| **Take class attendance** | Link to teacher UI to log student attendance for their classes (Phase B in Teacher Workflow Center plan). | High |
| **Lesson plans** | Link to lesson plan submission and approval (Phase C in plan). | Medium |
| **Deadline countdown** | If grading deadlines exist, show "Marks due in X days" in step 3. | Low |
| **My timetable** | Read-only timetable view for the teacher (when timetable UI exists). | Medium |

---

## Parent Workflow Center

| Improvement | Description | Priority |
|-------------|-------------|----------|
| **Pending signatures** | If signature requests exist, add a step or badge: "1 document to sign". | Medium |
| **Overdue finance** | Highlight "X overdue invoice(s)" in hero and step 3. | Done (badge in hero) |
| **First-child results link** | When only one child linked, "View results" could point directly to that child's results page. | Low |
| **Report card available** | Badge or step progress: "1 new report card" when term is published and parent hasn’t viewed. | Low |

---

## Cross-cutting

- **Mobile:** All three workflow centers use responsive grids; ensure touch targets and spacing are good on small screens.
- **i18n:** If the platform is localized, ensure step titles, tips, and labels are translatable.
- **Feature flags:** Optional site setting to hide specific steps (e.g. hide "Certification" in admin workflow if not used).

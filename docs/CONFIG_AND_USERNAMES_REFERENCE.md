# Config and usernames reference

Single source of truth for deployment config and every **actual username** created by the project.

---

## 1. Render config (render.yaml)

| Item | Value |
|------|--------|
| **buildCommand** | `./build.sh` |
| **preDeployCommand** | `.venv/bin/python manage.py migrate --noinput && .venv/bin/python manage.py seed_render_users` |
| **startCommand** | `.venv/bin/gunicorn config.wsgi:application` |
| **DEBUG** | `0` |
| **DATABASE_URL** | From database `school-management-db` (connectionString) |
| **ALLOWED_HOSTS** | `school-management-system-2kzk.onrender.com` |
| **SECRET_KEY** | Generated by Render |
| **ADMIN_PASSWORD** | **You must set this in Render Dashboard → Environment** (secret). Used by `seed_render_users` for admin, teacher1, Parent1. |

**Required in Dashboard:** Add `ADMIN_PASSWORD` (e.g. Sch00l_1234) so the preDeployCommand can create the three login accounts.

---

## 2. Usernames created on Render (preDeployCommand → seed_render_users)

These are created only when `ADMIN_PASSWORD` is set and `seed_render_users` runs.

| Username | Password | Role | Created by |
|----------|----------|------|------------|
| **admin** | Value of `ADMIN_PASSWORD` | Superuser | `ensure_superuser` |
| **teacher1** | Value of `ADMIN_PASSWORD` | Teacher | `create_teacher_parent_accounts` |
| **Parent1** | Value of `ADMIN_PASSWORD` | Parent | `create_teacher_parent_accounts` |
| **principal1** | Value of `ADMIN_PASSWORD` | Principal | `create_teacher_parent_accounts` |

**Actual usernames (exact):** `admin`, `teacher1`, `Parent1`, `principal1` — case-sensitive; parent is `Parent1` with capital P.

## 4. Summary: all actual usernames by source

**From seed_render_users (Render only):**  
`admin`, `teacher1`, `Parent1`

**From ensure_superuser (when you run it):**  
`admin` (default; or whatever you pass to `--username`)

**From seed_buea_synthetic:**  
- Teachers: `teacher_buea_01` … `teacher_buea_10` (small) or … `teacher_buea_20` (full)  
- Admins: `admin_buea_01`, `admin_buea_02`, `admin_buea_03`, `admin_buea_04`, `admin_buea_05`  
- Bursar: `bursar_buea`  
- Parents: `parent_buea_001` … `parent_buea_150` (small) or … `parent_buea_450` (full)

**Students:** No login accounts. Students exist as **StudentProfile** only (e.g. matricule BUEA/2025/001); parents log in to see them.

## 5. Database config (config/settings.py)

- **DATABASE_URL set** → PostgreSQL (production / Render).
- **DATABASE_URL not set** → SQLite; file is `db_working.sqlite3` (or `DB_FILE` env).
- **On Render (`RENDER=true`):** DATABASE_URL is required; app raises if missing so the service does not run with an empty SQLite file.

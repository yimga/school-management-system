# Config and usernames reference

Single source of truth for deployment config and every **actual username** created by the project.

---

## 1. Render config (render.yaml)

| Item | Value |
|------|--------|
| **buildCommand** | `./build.sh` |
| **preDeployCommand** | `.venv/bin/python manage.py migrate --noinput && .venv/bin/python manage.py seed_render_users` |
| **startCommand** | `.venv/bin/gunicorn config.wsgi:application` |
| **DEBUG** | `0` |
| **DATABASE_URL** | From database `school-management-db` (connectionString) |
| **ALLOWED_HOSTS** | `school-management-system-2kzk.onrender.com` |
| **SECRET_KEY** | Generated by Render |
| **ADMIN_PASSWORD** | Optional. Set in Render Dashboard → Environment (secret). Used by `seed_render_users` **only for tenant demo users** (teacher1, Parent1, principal1). Not used for the platform admin account. |

**Platform vs tenant credentials:** Platform super-admin and tenant users do not share credentials. The platform admin is always `admin` / `admin`; tenant demo users (when seeded) use `ADMIN_PASSWORD`. Set `ADMIN_PASSWORD` in Dashboard only if you want `seed_render_users` to create/update teacher1, Parent1, and principal1.

## 2. Usernames created on Render (preDeployCommand → seed_render_users)

`seed_render_users` runs on every predeploy. It always ensures the platform super-admin; it creates tenant demo users only when `ADMIN_PASSWORD` is set.

| Username | Password | Role | Created by | Notes |
|----------|----------|------|------------|-------|
| **admin** | **admin** (fixed) | Superuser | `ensure_superuser` | Platform only; change with `changepassword admin`. |
| **teacher1** | Value of `ADMIN_PASSWORD` (if set) | Teacher | `create_teacher_parent_accounts` | Only when ADMIN_PASSWORD is set. |
| **Parent1** | Value of `ADMIN_PASSWORD` (if set) | Parent | `create_teacher_parent_accounts` | Only when ADMIN_PASSWORD is set. |
| **principal1** | Value of `ADMIN_PASSWORD` (if set) | Principal | `create_teacher_parent_accounts` | Only when ADMIN_PASSWORD is set. |

**Actual usernames (exact):** `admin`, `teacher1`, `Parent1`, `principal1` — case-sensitive; parent is `Parent1` with capital P.

### Platform vs tenant credentials (summary)

| Context | Username | Password | Purpose |
|---------|----------|----------|---------|
| **Platform (super-admin)** | admin | admin (fixed) | /super/, /admin/, platform management. Change with `python manage.py changepassword admin`. |
| **Tenants (demo users)** | teacher1, Parent1, principal1 | ADMIN_PASSWORD or `--password` when running `create_teacher_parent_accounts` | Tenant Backend/portal; not shared with platform admin. |

## 5. Database config (config/settings.py)

- **DATABASE_URL set** → PostgreSQL (production / Render).
- **DATABASE_URL not set** → SQLite; file is `db_working.sqlite3` (or `DB_FILE` env).
- **On Render (`RENDER=true`):** DATABASE_URL is required; app raises if missing so the service does not run with an empty SQLite file.

# Region pack roadmap (§0.1.1 GTM)

Priority order for **installable** region presets (moe_presets + `REGIONAL_POLICY_PACKS` + education_dna):

| Region | Preset keys | Statutory / exams |
|--------|-------------|-------------------|
| India | CBSE, ICSE, state boards | Board exam exports |
| Singapore | MOE | PSLE/O-Level templates |
| Canada | ON, BC, AB provincial | Provincial returns |
| Australia | ACARA states | NAPLAN-adjacent reporting |
| Brazil | ENEM-oriented | Ministry CSV |
| MENA | Extend existing AR/EN packs | Country-specific ministry |

Each row = one pack milestone: RegionConfig, grading scale, term model, report stubs, signup deep link.

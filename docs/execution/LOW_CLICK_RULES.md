# Low-Click Rules (D4)

- **Purpose-built role homes:** Each role (admin, teacher, registrar, parent) has a single entry point; dashboard and workflow hubs resolve by role.
- **Outcome-first:** Console and Setup Studio use outcome labels (e.g. "Standardize grading", "Configure branding") not jargon.
- **Preview-before-commit:** Theme, report card, and feature control support preview; apply only when user confirms.
- **Guided paths:** Setup Studio (/setup-studio/), Console domains (/siteconfig/console/), workflow hub, dashboard hub.

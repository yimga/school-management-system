Fix buckets — apply the page-aware primitive that matches the page's content
  • FILL single-column content in a wide canvas → for a tall form use .cp-form-grid (flows fields into 2–4 columns, shortens AND fills); for a browse-able list use .cp-grid .cp-grid-2/3 on .cp-card (or row g-3 col-*).
  • CENTER genuinely narrow single form / settings toggle that is unreadable full-width → .content-measure (page-aware readable measure via --rmc-measure; symmetric margins). Older equivalent already on main: .content-max-640/520.
  • RAIL primary work + secondary context/aside → two-pane via .rmc-page-horizon (relocates stacked content into the right gutter; auto-stacks on narrow screens) or data-rmc-balanced-layout="*-rail".
  • LEAVE already fills/centers/rails, or narrow by design — no change.
  • REVIEW ambiguous — needs a human read before acting.

Note: the page-aware primitives .content-measure / .cp-form-grid / .rmc-page-horizon were authored in static/css/rmc-class-grammar.css as the canonical cure for this exact problem and are the preferred fix.

1. Create tenant  
2. Add classes, students, teachers  
3. Take attendance  
4. Enter marks  
5. Generate report  
6. Create invoice  
7. Capture payment / receipt (PSP or manual fallback)  
8. Parent / teacher portal access  
9. Offline sync + conflict resolution (if applicable)
